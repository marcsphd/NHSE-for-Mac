This independent native Mac editor primarily adapts NHSE save formats and editing features. ACNH-Save-Editor provided the initial foundation and reused encryption and hashing code. It is not an official release of either upstream project.

- Original application, item names, icon, and portable AES / XorShift / integer / Murmur3 routines: **cbreezy210/ACNH-Save-Editor**, commit `731c2284195bf4a56699709fb053a2124cd8fba2`, MIT, copyright 2026 cbreezy210. Original license is retained at the repository root and bundled as `Upstream-LICENSE.txt`.
- Save format reference, version descriptors, region offsets, item-kind metadata, and stack limits: **kwsch/NHSE**, GPL-3.0. See `NHSE.Core/Hashing/FileHashRevision.cs`, `Save/Meta/RevisionChecker.cs`, `Save/Offsets/PersonalOffsets30.cs`, `Save/Offsets/MainSaveOffsets30.cs`, `Structures/Item/ItemInfo.cs`, and `Resources/byte/item_kind.bin`. https://github.com/kwsch/NHSE . Reference commit is recorded in `REFERENCE-REVISION.txt`.
- Map and villager adaptation sources: `NHSE.Core/Save/Offsets/MainSaveOffsets30.cs`, `Structures/Map/Terrain/TerrainTile.cs`, `TerrainUnitModel.cs`, `Structures/Map/TileGridViewport.cs`, `Structures/Building/Building.cs`, `Structures/Villager/Villager2.cs`, `GSaveMemory.cs`, `Editing/FieldItem/FieldItemDropper.cs`, and `Structures/Map/Layers/LayerItem.cs`. Terrain identifiers, known villager identities, names, default personalities/catchphrases, base-acre collision data (`outside.bin`), and portraits from `NHSE.Sprites/Resources/Villagers` are included with attribution. Animal Crossing character artwork belongs to Nintendo and its respective rights holders.
- Player/island settings adaptation: `NHSE.Core/Save/Files/Personal.cs`, `MainSave.cs`, `Save/Offsets/PersonalOffsets30.cs`, `MainSaveOffsets30.cs`, `Save/Meta/HorizonSave.cs` (`ChangeIdentity`), `Hashing/FileHashRevision.cs`, `Structures/Misc/Hemisphere.cs`, `AirportColor.cs`, `IslandFlowers.cs`, and `NHSE.WinForms/Subforms/Map/FruitsFlowersEditor.cs`. Identity replacement uses the complete ID-and-name record; numeric IDs and encryption headers are retained.

The native tab uses the saved unlocked capacity while preserving remaining physical storage records. The UI, pagination, filtering, draft integration, and verification are implemented in Swift/Python for this port.

These are NHSE's bundled menu icons; optional external per-item/variation image packs are not bundled.
- Nintendo and Animal Crossing are trademarks of their respective owners. This project is unaffiliated with Nintendo.

The Mac port rewrites the UI and file handling, removes Switch-specific dependencies, adds strict save validation and transactional backups, recalculates save hashes, and removes the original blanket writes to unrelated main.dat fields. It preserves original encryption headers for changed data.

## Mac app icon

The Inventory Tiles app icon (selected concept 6) and saved Leaf & Pencil alternate (concept 1) were generated specifically for this project using the built-in image generator. They replace the earlier app icon; the upstream Switch icon remains in the original Switch sources. Original concepts and preparation prompts are preserved with the project. See `ICON-PROVENANCE.json`.

## Original building illustrations

The 14 `building-icon-*.png` files are original AI-generated fan artwork produced with the built-in imagegen tool for this Mac editor. They are inspired by Animal Crossing and are not official Nintendo or NHSE assets. Prompts and spacing sources are recorded in `Design/Map/`. Existing Nintendo/NHSE inventory and character artwork retains the attribution above.
