# Yolo example island

This complete ACNH 3.0.3 save snapshot was contributed by the project owner for inclusion in Git and distribution as the default example data. It replaces the schematic synthetic island in Explore a Preview.

`Save/` contains the original snapshot files. `manifest.json` records their SHA-256 hashes. The app validates and reads this bundled copy, then keeps its data in memory with save and export disabled in preview mode. Playing with the example never writes to the owner's original game save.
